What I've Discovered

NLP · Deep Learning · Machine Learning · UT Arlington
Fine-Grained Emotion Detection in Text using DistilBERT
Fine-tuned a DistilBERT Transformer model on the GoEmotions dataset — 58,000 Reddit comments annotated for 27 emotion categories — for multi-label emotion classification consolidated into 8 broad categories. Framed the task as a multi-label classification problem to capture co-occurring emotions (e.g. fear and joy simultaneously), overcoming the limitations of traditional single-label sentiment analysis.
Engineered a training pipeline with three key innovations: class-balanced loss weighting to address dataset imbalance across rare emotions like fear and disgust; dual learning rates (lower for pre-trained layers, higher for the classification head) to prevent catastrophic forgetting; and per-emotion threshold tuning to optimise precision-recall for each class independently. The resulting system achieved a Micro-F1 of 0.8339 and Macro-F1 of 0.81 — an 81% relative improvement over the published GoEmotions BERT baseline.
